# Credit-Card-Fraud-Detection-System
Built a machine learning-based Credit Card Fraud Detection System to identify fraudulent transactions using customer and transaction features. Applied data preprocessing, EDA, SMOTE, Random Forest, and created a Power BI dashboard to analyze fraud patterns and risk levels.

## PROJECT OVERVIEW
Built a Credit Card Fraud Detection System using Machine Learning to identify potentially fraudulent transactions and classify transaction risk levels.

## OBJECTIVES
1. Detect fraudulent transactions
2. Analyze transaction patterns and customer behavior
3. Handle imbalanced fraud data
4. Predict fraud probability
5. Classify transactions into High, Medium, and Low Risk
6. Visualize fraud insights using Power BI

## TECHNOLOGIES USED
Python
Pandas & NumPy
Scikit-learn
SMOTE – Handling class imbalance
Random Forest – Fraud classification
SQL – Data analysis
Power BI – Dashboard and visualization

## PROJECT WORKFLOW
Data Collection → Data Cleaning → EDA → Feature Engineering → Class Imbalance Handling → Model Training → Evaluation → Fraud Probability & Risk Classification → Power BI Dashboard

## MACHINE LEARNING
A Random Forest Classifier was used to predict whether a transaction is fraudulent.

The model also generates a fraud probability, which is used to categorize transactions into:

🔴 High Risk
🟠 Medium Risk
🟢 Low Risk

## POWER BI DASHBOARD
